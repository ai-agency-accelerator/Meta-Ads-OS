# clientes/

Un espacio por cliente o proyecto propio: `clientes/<slug>/`. Se crea con `/cliente-nuevo <nombre>` a partir de
`plantillas/cliente/`.

Todo lo que hay aquí (salvo este archivo) es **tuyo**: git no lo sube y `/actualizar` no lo toca. Si quieres copia de
seguridad, guarda esta carpeta en un repositorio **privado** propio o en tu nube.

| Archivo o carpeta | Qué es |
|---|---|
| `ficha.md` | Datos del negocio, IDs de Meta, topes de gasto y economía. La cabecera la leen las herramientas |
| `estado.md` | Fase (F0–F6) y checklist verificable |
| `change-log.md` | Cada cambio en Meta, con hipótesis y fecha de evaluación |
| `registro-creativo.csv` | Cada anuncio con sus métricas y resultados de negocio |
| `datos/` | Exportaciones sin datos personales |
| `privado/` | Exportaciones con datos personales (emails, teléfonos). Nunca se comparten |
| `creativos/`, `informes/`, `auditorias/`, `investigacion/`, `planes/` | Entregables |
