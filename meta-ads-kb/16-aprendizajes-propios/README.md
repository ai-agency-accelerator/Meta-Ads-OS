# 16 · Aprendizajes propios

> **Tus aprendizajes no van aquí: van en `aprendizajes/`, en la raíz del proyecto** (ver
> [`aprendizajes/README.md`](../../aprendizajes/README.md)). Esta base de conocimiento forma parte del producto y se
> sustituye en cada actualización; `aprendizajes/` es tuyo, git no lo sube y `/actualizar` no lo toca.

Esta sección recoge solo aprendizajes de cuentas reales que ya se han verificado e incorporado al producto en una
versión, siempre anonimizados: tipo de negocio y mercado, nunca nombres de clientes, marcas ni IDs. Llegan por el
proceso de mantenimiento del producto, después de que `curador-conocimiento` compruebe que no son ruido de una sola
cuenta.

Formato por entrada: fecha · tipo de negocio y mercado (sin nombre) · contexto · cambio o test · resultado · tamaño de
muestra y ventana · etiqueta **[EMPIRICAL]** · ¿confirma o contradice algo de la base? (enlace).
